# platform-scorecard

An open standard for evaluating platform safety policies — automated scoring
based on public policy documents. No more self-grading.

## Status
RFC Stage — help us define the standard

## How It Works
1. Each platform's public safety policy is parsed against the scorecard schema
2. Scores are generated across 5 dimensions: transparency, enforcement, reporting, age verification, data minimization
3. Results published publicly — platforms can dispute scores via PR

## Dimensions
- Transparency (0-20): Are policies written in plain language?
- Enforcement (0-20): Are consequences clearly defined?
- Reporting (0-20): Can users report harm easily?
- Age Verification (0-20): Are age gates meaningful?
- Data Minimization (0-20): Is children's data minimized?

## Contributing
Open an issue to propose a new dimension, challenge a score, or submit a platform.
